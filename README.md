# Momento

**A simple To-Do List for your everyday moments.**

Momento는 Vanilla JavaScript로 제작한 심플한 To-Do List 웹페이지입니다.
이름을 입력하면 인사말을 보여주고, 현재 시간과 날씨를 확인하며 오늘의 할 일을 관리할 수 있습니다.

## 기능

- **Personal Greeting** : 이름을 입력하면 인사말 표시
- **Live Clock** : 현재 시간을 실시간으로 표시
- **Weather** : 현재 위치 기반 날씨 및 기온 표시
- **To-Do List** : 할 일 추가 및 삭제
- **Local Storage** : 브라우저에 사용자 이름과 할 일 목록 저장
- **Random Quotes** : 20개의 명언 중 하나를 랜덤으로 표시
- **Background Image** : 랜덤 배경 이미지 적용

## 기술 스택

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- OpenWeather API
- Local Storage
